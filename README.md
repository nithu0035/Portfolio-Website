# AI/ML Engineer Portfolio Website

A modern portfolio website showcasing AI/ML projects, full-stack applications, technical skills, certifications, and professional experience. Built with React and modern web technologies to provide an interactive, responsive, and production-ready developer portfolio.

## Live Demo

🌐 https://nithu0035.github.io/Portfolio-Website

## Key Features

- Professional portfolio with responsive design
- Interactive 3D hero section powered by Three.js
- Smooth UI animations using Framer Motion
- AI/ML project showcase with GitHub integration
- Technical skills categorized by domain
- Certifications with embedded document viewer
- Resume download functionality
- Contact section for professional networking
- Optimized deployment using GitHub Pages



## Technology Stack

| Category | Technologies |
|----------|--------------|
| Frontend | React, Vite |
| Styling | Tailwind CSS |
| Animation | Framer Motion, AOS |
| 3D Graphics | Three.js, React Three Fiber |
| UI Effects | tsParticles, React Icons |
| Charts | Chart.js |
| Deployment | GitHub Pages |

## Installation

```bash
git clone https://github.com/nithu0035/Portfolio-Website.git

cd Portfolio-Website

npm install

npm run dev
```



## Production Build

```bash
npm run build
```



## Deployment

```bash
npm run deploy
```
